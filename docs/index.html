Nhi làm được gì?

Phần cứng nhỏ gọn chạy firmware Xiaozhi, kết nối tới Gemini Live để hội thoại thời gian thực.

🗣️

Nói tiếng Việt tự nhiên

Gemini Live nghe và trả lời trực tiếp bằng giọng nói, ngắt lời được, phản hồi chưa tới 1 giây.

👋

Gọi không cần nút

Nói "Chào Nhi" (wake word chạy trên chip) hoặc đưa tay lại gần cảm biến laser VL53L0X.

👀

24 biểu cảm mắt

Mắt RoboEyes trên màn ILI9341: vui, buồn, thả tim, ngủ gật, kính râm… kèm phụ đề câu trả lời.

🔎

Tự tra Google

Tin tức, thời tiết, câu hỏi khó: Nhi tự tìm kiếm rồi tóm tắt ngắn gọn.

🎓

Nhân vật riêng

Tính cách và kiến thức về trường, bộ môn, sự kiện sửa trong 2 file văn bản, không cần lập trình.

💸

Miễn phí

Server chạy ngay trên laptop, dùng gói miễn phí của Google AI Studio.

Kiến trúc

Robot gửi giọng nói (Opus 16 kHz) qua WebSocket tới laptop; laptop chuyển tiếp tới Gemini Live và đẩy giọng trả lời về robot.

Cài đặt nhanh

Chi tiết từng bước có trong README của repo.

  1. Lấy Gemini API key miễn phí tại aistudio.google.com/apikey.
  2. Vào server/nhi-live, chuột phải setup.ps1 → Run with PowerShell (nên chạy quyền Admin). Script tự cài Python, thư viện, hỏi key, mở tường lửa và tạo shortcut.
  3. Bấm đúp shortcut Nhi Live trên Desktop. Để nguyên cửa sổ đó trong suốt buổi demo.
  1. Cài ESP-IDF v6.0.1.
  2. Tải Xiaozhi và áp các patch của Nhi: 
    git clone https://github.com/78/xiaozhi-esp32.git
cd xiaozhi-esp32 && git checkout c0fe42a
git am ..\ai-robot\firmware\patches\*.patch
  3. Build và nạp: 
    python scripts/build.py esp32s3-weact-dog --language vi-VN
idf.py -p COM8 flash monitor
  1. Robot khởi động lần đầu sẽ phát Wi-Fi Xiaozhi-XXXX (hoặc nhấn BOOT lúc đang quét Wi-Fi).
  2. Điện thoại vào Wi-Fi đó, mở 192.168.4.1, chọn Wi-Fi mà laptop đang dùng.
  3. Ô OTA URL: http://<IP-laptop>:8003/xiaozhi/ota/ → Lưu. Nói "Chào Nhi"!
